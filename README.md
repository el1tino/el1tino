Focused on security operations: detection, phishing analysis, incident response and putting AI to work inside security tooling.


### Projects

| Project | What it does |
|---|---|
| [undercover](https://github.com/el1tino/undercover) | Email DLP and phishing-detection pipeline: PII and secret scanning, rule-based and ML phishing detection, sender anomaly detection, one risk score, MITRE ATT&CK tagging and SIEM export |
| [Corvin](https://github.com/el1tino/Corvin) | Incident-response orchestrator for EU reporting rules: classifies incidents under DORA, NIS2 and GDPR, tracks the legal deadlines, drafts the notifications and keeps a tamper-evident audit trail |
| [recon-bridge](https://github.com/el1tino/recon-bridge) | Reconnaissance toolkit that AI models can drive over MCP, built for authorised testing: strict scope enforcement, rate limiting and an append-only audit log |
| [pantheon](https://github.com/el1tino/pantheon) | Several AI models debate a goal, vote on roles and build the result, with generated code run in locked-down Docker containers |
